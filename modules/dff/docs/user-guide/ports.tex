\section{Port Descriptions}

The ports for \textbf{Dff} are shown below in
Table~\ref{table:ports}. The width of several ports is controlled
by the following parameter:

\begin{itemize}[noitemsep]
  \item \textit{width} is the width the d and q ports in bits
\end{itemize}
