\section{Simulation}

\subsection{Tests}
The test bench runs highly randomized tests on the configurations defined in the \texttt{SyncFifo.simConfigMap}. There are two flavors of tests:

\begin{itemize}
  \item {Directed tests that fill the FIFO with random data and then read back
        the results to verify that the read data matches the writted data.}
  \item {Assertion tests that insure that illegal configuration are not
        compiled.}
\end{itemize}

\subsection{Code coverage}

Code coverage is greater than the chiselWare requirement of 90\% statement
coverage and 95\% branch coverage.

\subsection{Running simulation}

Simulations can be run directly from the command prompt as follows:

\texttt{\$ sbt test}

or from make as follows:

\texttt{\$ make test}
